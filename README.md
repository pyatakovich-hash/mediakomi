# Медиакоми

Симулятор покупателя: угадай цену квартиры в Инте по фото из настоящего объявления. За игру — 10 случайных квартир, бегунок цены, баллы за точность и итоговое звание.

Next.js 16 + TypeScript + Tailwind CSS 4. Фронтенд без бэкенда, в рантайме только `next`, `react`, `react-dom`.

## Запуск

Нужен Node.js 20.9+ (лучше 22 LTS или новее).

```bash
npm install
npm run photos   # скачать фото из таблицы (один раз; уже скачанные пропускаются)
npm run dev      # http://localhost:3000
```

Продакшен-сборка локально:

```bash
npm run build
npm start        # http://localhost:3000
```

## Как устроена игра

- Раунд — 10 случайных объявлений без повторов из `src/data/flats.json`.
- Бегунок логарифмический: от 50 тыс. до 5 млн ₽, старт — 500 тыс. Цена округляется до 5/10/50/100 тыс. в зависимости от суммы, кнопки −/+ для точной подстройки. При первом запуске бегунок сам покачивается — подсказка, что его надо двигать.
- Баллы за квартиру: `100 × (1 − |log₂(оценка / цена)|)`, но не меньше 0. Точно — 100, ошибка на 10% — около 85, ошибка в 2 раза в любую сторону — 0. Максимум за игру — 1000.
- После ответа показываем реальную цену, на сколько оценка больше или меньше и переплату/недоплату в рублях.
- Итог: 450 баллов и больше — «Опытный инвестор». Иначе смотрим на сумму ошибок в рублях: переплата — «Щедрый инвестор», недоплата — «Скряга».

Вся логика — в `src/lib/game.ts`.

## Данные и фото

- Источник — `data/komi_flat.csv` (колонки: ссылка, фото 1–5, цена, цена за кв м, описание, улица).
- `npm run photos` скачивает фото в `public/photos` (WebP до 960 px) и собирает `src/data/flats.json`. В игру попадают только квартиры, у которых есть фото.
- `npm run data` — пересобрать JSON по уже скачанным фото, без сети.
- Новые данные: заменить `data/komi_flat.csv` и запустить `npm run photos`.

Фото лежат в репозитории и отдаются с того же домена — внешних запросов у страницы нет. Грузится только текущее фото и следующее, первое фото следующей квартиры подгружается заранее.

## Деплой

Vercel:

1. Залить репозиторий на GitHub.
2. На vercel.com: Add New → Project → импортировать репозиторий. Настройки по умолчанию (Framework: Next.js, Build Command: `npm run build`).
3. Ссылка «Код на GitHub» в подвале берётся из `src/config.ts`; её можно переопределить переменной окружения `NEXT_PUBLIC_REPO_URL`.

Любой хостинг с Node.js: `npm ci && npm run build && npm start` (порт задаётся переменной `PORT`).

## Безопасность

Заголовки задаются в `next.config.ts` для всех страниц и файлов:

- `Content-Security-Policy` — скрипты, картинки, шрифты и запросы только со своего домена, без inline-скриптов, `frame-ancestors 'none'`;
- `Referrer-Policy: strict-origin-when-cross-origin`;
- `X-Frame-Options: DENY`;
- `X-Content-Type-Options: nosniff`;
- `Permissions-Policy` — камера, микрофон, геолокация, оплата и USB отключены.

Почему Pages Router и `next build --webpack`: так страница собирается статически и без inline-скриптов, поэтому строгий CSP работает без nonce (сборка Turbopack добавляет inline-загрузчик). Встроить игру в iframe на другом сайте нельзя из-за `X-Frame-Options`; если понадобится — заменить на `frame-ancestors https://адрес-сайта`.

src/lib/game.ts         баллы, тексты, суммы, бегунок
src/components/         галерея, бегунок, подвал, пятиэтажка
